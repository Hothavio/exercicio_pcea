# exercicio_pcea

## Fazer um fork desse repositório e enviar uma alteração no README.md, com um parágrafo sobre essa matéria.

A matéria tem como objetivo introduzir os conceitos essenciais da lógica de programação, estrutura de algoritmos e funcionamento básico dos computadores. Ao longo do semestre, além da prática com funções e entrada de dados, também foram abordados temas importantes como licenciamento de software (entendendo os tipos de licença e seus impactos legais), a diferença entre arquiteturas CISC e RISC (relacionadas à forma como os processadores executam instruções) e paralelismo (fundamental para o desempenho em arquiteturas modernas). Esses conteúdos ajudam a formar uma base sólida para compreender como os programas são escritos, executados e otimizados nos sistemas computacionais atuais.
